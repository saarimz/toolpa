# Hardening

## Slice 1

One chain. A sine, seeded noise, or a sample identified by the SHA-256 of its file bytes goes through Tone (lowpass, then gain), then a meter and the output. Live playback and the offline WAV render use that same chain document and hash. The chain saves as a content-addressed `.toolpa` file in the origin private file system, with parent ids in the hashed bytes.

- Telemetry is `@toolpa/trace` only. Tests write NDJSON. The browser keeps a ring buffer. The network guard fails a run that calls `fetch`, XHR, WebSocket, or `sendBeacon` off the allow list. There is no third-party analytics.
- Offline goldens pin the sine, noise, and sample WAV bytes. A fresh Elementary renderer is used for every render so the bytes stay stable.
- `pnpm slice:gate` runs the unit tests, the Chromium, Firefox, and WebKit browser tests, renders the goldens again, and prints the local telemetry report.
- Artifact bytes live in the origin private file system when it opens, and in IndexedDB when it does not. Chromium, Firefox, and WebKit save, load, and parent walk are gating. Live playback and offline render still run on WebKit.
- Native MP3 decode is checked on all three browsers. If WebKit's `decodeAudioData` fails, that one check is recorded and is not gating. The canonical decoder is the bundled mpg123 WASM, and that path is gating everywhere.
- A hosted chat model stays behind `RemoteModel` and throws `NOT_CONFIGURED` until a gateway or secondary provider is selected and `TOOLPA_ALLOW_NETWORK=1`. The agent loop uses `MockModel` and records the prompt without a secret. `RemotePromptProvider` with no complete function throws `NOT_CONFIGURED`. The local provider hashes the prompt and does not call the network. MIDI hardware stays behind `MidiPort`. `openHardwarePort` throws `MIDI_HARDWARE_FOLLOWUP`. Tests use a fake port. Slice 1 still rejects a chain that carries `voices` or a subpatch (`SLICE_UNSUPPORTED`). Slice 2 adds a separate `instrument` document. Its notes lower to sine voices, those voices are summed, and Tone is applied once to the sum. A test asserts the lowered graph contains one `svf`. `el.time()` counts samples in the offline renderer, so note gates are scheduled in samples. An effect placed inside a voice is still out of scope.
- The chain hash is SHA-256 of the canonical chain document. It is not a per-node FNV, and it is not `@elemaudio/core`'s `hashNode`. Slice 9 adds that FNV on the IR, beside the SHA-256 document id. Chain goldens stay SHA-256.
- The sample-exact path copies the registered frames. Elementary's sample player interpolates, so that player is not the identity check. A missing buffer throws `SampleError` and does not render silence.
- The playground and the committed goldens are 44.1 kHz. The lowpass band measurement and the pitch check render at 48 kHz.
- `.toolpa` pack/unpack/verify is a store-method zip (fflate, MIT) with a `tpa1:sha256:` content id. The zip holds `toolpa.json`, `graph.json`, `verify.json`, `previews/fingerprint.json`, and any referenced `samples/<sha256>.wav` bytes. The playground OPFS library stores that zip. A reader still opens the older canonical JSON envelope, so a file saved before this change reloads. The envelope hash remains the OPFS id and the parent pointer. Download writes `<name>-<hash12>.toolpa` for the current chain and its samples. Open, including a drop onto the playground, runs the zip-safety and hash checks, restores the chain, and saves it with the parent list from the manifest. A tampered, invalid, or oversized file shows the error and does not replace the chain.
- License audit: first-party packages are GPL-3.0-or-later. Direct dependencies must be MIT, BSD, Apache-2.0, LGPL, ISC, 0BSD, or OFL-1.1. AGPL is rejected. OFL-1.1 is the SIL font license on the playground's Geist face, which the FSF lists as GPL-compatible.
- WAV export writes PCM-16, PCM-24, and 32-bit IEEE float. Float files include a `fact` chunk. Every render embeds an `ITOK` chunk: format version 1 and the SHA-256 of the chain document, so the WAV points back at its `.toolpa` artifact. PCM-16 and PCM-24 round-trip within one least significant bit. Float32 round-trips bit-exactly. A reader that only understands `fmt` and `data`, and the browser's `decodeAudioData`, both ignore `ITOK`.
- The chain identity is SHA-256 of the canonical document. That is the registry design, kept on purpose.
- Loaded WAV and MP3 files may be at most 50 MB. One byte over that throws `LOADER_TOO_LARGE` before decode. The MP3 decoder remains mpg123 WASM: one implementation in Node and in every browser, instead of each browser's `decodeAudioData`.
- The gate report prints nearest-rank p50 and p95 for a 0.25 s sine render and for WAV and MP3 decode, from 20 runs.
- `.github/workflows/slice.yml` runs `pnpm slice:gate` after starting a null PulseAudio sink. Firefox on the GitHub runner does not open an audio device without that sink.
- `pnpm toolpa render` writes a WAV for a chain file. Publishing packages to a registry needs credentials and is a follow-up.
- Slice 8 maps beats to seconds and launches a clip into the existing live renderer. The plan's lookahead scheduler, swing, and the three playground demos stay follow-ups with the deferred engine. `openMicrophone` throws `MIC_FOLLOWUP`. `InputBus` is a silent local bus because the gate has no microphone.
- The slice 5 push on `175b180` failed because the suite probe exited on `EADDRINUSE` for port 43120. The same commit's pull-request run passed. Probe servers now stay up when the port is already bound, so Playwright can reuse the listener.
- A non-48 kHz sample is still resampled into the chain. The plan's Node path would have rejected it.
- Slice 13 lists Web MIDI devices through `requestMidiAccess`. Tests inject a fake access. `openHardwarePort` still throws `MIDI_HARDWARE_FOLLOWUP`. Slice 14 fills `InputBus` from an injected capture, or from `getUserMedia` when `live` is true. `openMicrophone()` with no arguments still throws `MIC_FOLLOWUP`. Slice 15 calls a model only when `allowNetwork` is true. The primary providers are the Vercel and Cloudflare AI gateways. Direct OpenAI-compatible chat and Ollama are secondary. The gate leaves `TOOLPA_ALLOW_NETWORK` unset, so `fetch` is not used. Tests stub `fetch`. `MockModel` stays the default. Slice 21 posts prompts only to same-origin `/api/agent`. The playground guard blocks gateway hosts. A 403 or 410 from Workers AI is shown on the page. Slice 22 does not replace a failed model reply with a canned instrument. A parse or model failure stays on the page. Silence, clipping, and NaN can be auto-adjusted and are labeled.
